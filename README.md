# womp (waste of money protocol) specification
The womp specification is a standardised specification for custom wasteof.money clients to implement new features.

## versioning
womp uses semantic versioning.

**womp 1.0.0 is currently the latest version**. Clients implementing womp are encouraged to keep their implementation as up to date as possible. There are no requirements on how womp must be implemented.

## suggestions
womp is intended to be an open standard anyone can help improve. If you have an awesome idea for womp, please feel free to open an issue!
